# 工程2: 仕様策定

## 本工程について

- 工程1の`環境セットアップ`を終えて本工程に到達しているはず。そのため、下書きの`Epic Issue`が対象プロジェクトに存在するはず。
- scaffoldにおいては`Epic Issue`を仕様の正本として扱う。
- 本工程では、変数が埋まるまで、ユーザーヒアリングもしくは調査を行い、`Epic Issue`を完成させる。

## 本工程のゴール

- `〇〇`が正しく実行され、次の工程「`基本設計`」用のセッションが別タブで開始したことをもって本工程のクリアとする。

## 実施内容

1. `ask_user`を使いユーザーに質問をしながら、`〇〇`コマンドに必要な情報を整理する。
2. `〇〇`コマンドにより`Epic Issue`に記載された調査項目の解消に取り掛かる。それぞれ、ユーザーへのヒアリングと調査を組み合わせて解消していく。
3. 調査項目の調査が終わったら、`〇〇`を実行し、調査項目を`Epic Issue`上でも解消する。
4. `Epic Issue`が完成したら`〇〇`を実行し、次の工程「`基本設計`」へと移る。

### 注意事項

- 基本設計や製品コード実装は行わない。
- 基本設計セッションに移る前に、調査項目はすべて必ず完了する。
