# 工程5: 検証

- 工程4の`詳細設計・実装`を終えて本工程に到達しているはず。
- 本工程では、システムの動作確認を行う。

## 本工程のゴール

- 動作確認表が正しく作成され、動作確認結果がすべてクリアされていること

## 実施内容

1. `Epic Issue`の内容をもとに、動作確認計画を立てる。動作確認事項のリストはチェックボックスにする。
2. 動作確認計画に基づき、動作確認を実行する
3. 動作確認がすべてクリアであれば、`〇〇`コマンドで`Epic Issue`を閉じ、実装の完了をユーザーに連絡する。
   不具合やエラーがあれば、実装セッションにherdr経由で修正依頼を行い、再度動作確認する。
